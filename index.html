About

This is a tool to create and edit interactive and animated effects built in p5.js using AI. Animation effects are triggered by mouse or touch interactions. Effects are created in three steps. First, describe the idea behind the effect. Second, break it down into simple steps. Third, write the code based on the steps. This tool uses generative AI to help with this process, however, as with all AI, the results may not be exactly what you want. Work back and forth with the AI system, and edit the code directly to get closer to what you are looking for.
